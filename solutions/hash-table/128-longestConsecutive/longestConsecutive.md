# 128.longestConsecutive(最长连续序列)

## 题目
给定一个未排序的整数数组 nums，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。
请你设计并实现时间复杂度为 **$O(n)$** 的算法。

示例:
输入: nums = [100,4,200,1,3,2]
输出: 4
解释: 最长连续序列是 [1,2,3,4]，长度为 4。

## 思路：哈希集合 + **只从"起点"开始数**

1. **所有数放进 `unordered_set`**（顺便去重）；
2. 遍历集合里每个 `num`：
   - **若 `num - 1` 也在集合里 → num 不是起点，直接跳过**；
   - 否则 num 是某段的起点：从它开始 `while(st.count(cur+1)) cur++`，数出这段长度；
   - 更新答案。
3. 返回最大长度。

## 为什么是 O(n)

- 一条连续段**只有 1 个起点**；
- 段里每个数，只在"从它自己那段的起点往后数"时被访问 **一次**；
- **所以每个数总共只被访问 O(1) 次** → 总 $O(n)$。

> 如果每个数都从头数一遍，就是 $O(n^2)$。
> **`if(!st.count(num-1))` 这一行，就是把"重复数"砍掉的关键。**

## 代码
```cpp
class Solution {
public:
    int longestConsecutive(vector<int>& nums) {
        unordered_set<int> st(nums.begin(), nums.end());
        int maxLen = 0;
        for (int num : st) {
            if (st.count(num - 1)) continue;   // num 不是起点 → 跳过
            int cur = num, curLen = 1;
            while (st.count(cur + 1)) {        // 从起点一路往后数
                cur++;
                curLen++;
            }
            maxLen = max(maxLen, curLen);
        }
        return maxLen;
    }
};
```

## 复杂度
- 时间：$O(n)$（哈希平均 $O(1)$）
- 空间：$O(n)$（集合）

## 要点

### 1. 为什么**不能用数组** —— 本题第一个岔路口

| 题 | 值域 | 能用数组吗 |
|---|---|---|
| **242 异位词** | 26 个字母 | ✅ `cnt[26]` |
| **128 最长连续** | **±10⁹** | ❌ **开不了** |

> **数组的大小 = 值域；`set` 的大小 = 元素个数。**
> 所以"遍历数组"是 $O(值域)$，"遍历 set"才是 $O(n)$。

**这一步判错，后面怎么优化都到不了 O(n)。**

### 2. `set` 还是 `map`？

这题只问"**某个数在不在**" → 不需要次数 → **`set` 就够**（比 map 省）。

> **判断标准：只要"在不在" → set；要"几次" → map。**
> （242/169 要计数 → 数组 / map；128 只要存在性 → set）

### 3. 负数
数组下标法**天然处理不了负数**；`set` 完全没问题。
（测试里专门放了 `[-1,0,1,-2]`。）

### 4. 遍历 `set` 而不是 `nums`
`for (int num : st)` 已经**去重**，省掉重复元素的外层重复检查。
遍历 `nums` 也能过，但重复多了会白跑。
