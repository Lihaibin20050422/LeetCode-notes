# 169.majorityElement(多数元素)

## 题目
给定一个大小为 n 的数组 nums，返回其中的**多数元素**。
多数元素是指在数组中出现次数 **大于 ⌊ n/2 ⌋** 的元素。
你可以假设数组是非空的，并且给定的数组总是存在多数元素。

示例:
输入: nums = [2,2,1,1,1,2,2]
输出: 2

## 思路一：哈希表（本题写法）

遍历一遍统计每个数的出现次数，再遍历哈希表找那个次数 `> n/2` 的。

```cpp
int majorityElement(vector<int>& nums) {
    unordered_map<int,int> cnt;
    int n = nums.size();
    for (int x : nums) cnt[x]++;
    for (auto& [val, c] : cnt) {        // C++17 结构化绑定
        if (c > n / 2) return val;
    }
    return -1;
}
```

## 思路二：摩尔投票（**最优，O(1) 空间**）

**核心思想：把"不同的两个数"两两抵消。** 多数元素出现次数超过一半，所以**抵消到最后，剩下的必然是它**。

```cpp
int majorityElement(vector<int>& nums) {
    int candidate = 0, count = 0;
    for (int x : nums) {
        if (count == 0) { candidate = x; count = 1; }
        else if (x == candidate) count++;
        else count--;                   // 不同的抵消掉
    }
    return candidate;                   // 本题保证存在，不用验证
}
```

## 复杂度

| 解法 | 时间 | 空间 |
|---|---|---|
| 哈希 | O(n) | **O(n)** |
| **摩尔投票** | O(n) | **O(1)** |

## 要点

### 1. `>` 而不是 `>=`
多数元素的定义是"出现次数 **> n/2**"。
`n/2` 是整数除法，n 奇偶都成立：
- n=7 → `7/2=3`，要 `>3` 即 ≥4；
- n=6 → `6/2=3`，要 `>3` 即 ≥4。

### 2. ⚠️ LC 169 和 "408 主元素" 的**关键差别**

| | 是否保证存在多数 | 要不要再扫一遍验证 |
|---|---|---|
| **LC 169** | **保证存在** | ❌ 不用 |
| **408 综12 主元素** | **不保证** | ✅ **必须验证** |

> 摩尔投票结束后，candidate **不一定是多数元素**（只是"可能"）。
> 408 的题不保证存在，所以**必须再扫一遍统计 candidate 的真实次数**，超过 n/2 才输出。

**同一套算法，LC 少写一步、408 必须多写一步**——差别就在"题目给的保证"。

### 3. 遍历 map 的写法
```cpp
for (auto& p : cnt)              // p.first 键 / p.second 值
for (const auto& p : cnt)        // 只读，加 const
for (auto& [val, c] : cnt)       // C++17 结构化绑定（推荐）
```
