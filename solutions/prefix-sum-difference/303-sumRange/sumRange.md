# 303. 区域和检索 - 数组不可变

## 题目

给定一个数组，多次查询区间 `[left, right]` 的元素和（下标从 0 开始，包含两端）。
数组**不可变**（构建后不会被修改）。

## 思路：预处理前缀和

**核心思想：用一次 $O(n)$ 的预处理，把每次查询从 $O(n)$ 降到 $O(1)$。**

定义：

```
P[i] = a[0] + a[1] + ... + a[i-1]     （P[0] = 0）
```

则区间和：

```
sum(left, right) = P[right + 1] - P[left]
```

### 为什么数组要开 `n + 1`

`P[0] = 0` 是一个**哨兵**：

| 不用哨兵 | 用哨兵 |
|---|---|
| `left == 0` 要特判 | **统一公式，无特判** |
| `sum = P[right]` | `sum = P[right+1] - P[0]` |

**一处哨兵，省掉一整类边界判断。** 这是前缀和写法的标准约定。

## 代码

```cpp
void NumArray(vector<int>& nums, vector<int>& Prefix)
{
    int n = nums.size();
    Prefix.resize(n + 1, 0);
    for(int i = 0;i < n;i++){
        Prefix[i+1] = Prefix[i] + nums[i];
    }
}

int sumRange(vector<int>& Prefix, int left, int right)
{
    return Prefix[right+1] - Prefix[left];
}
```

> 力扣原题要求写成类（`NumArray` 的构造函数里建表），这里用自由函数保持和你的代码风格一致，逻辑完全相同。

## 复杂度

| 操作 | 复杂度 |
|---|---|
| 构建 | $O(n)$ |
| **每次查询** | **$O(1)$** |
| 空间 | $O(n)$ |

对比暴力：每次查询 $O(\text{区间长度})$，$q$ 次查询是 $O(nq)$。

## 要点

### 1. 前缀和的适用前提

> **数组不变，且查询的是"连续区间"的和。**

一旦数组需要修改（比如单点更新），前缀和每次都要重建，退化成 $O(n)$——那时要用**树状数组**或**线段树**。

### 2. 前缀和的三种延伸（后面几题都会遇到）

| 形式 | 解决的问题 | 代表题 |
|---|---|---|
| **一维前缀和** | 区间和查询 | 303（本题） |
| **二维前缀和** | 子矩阵和 | 304 |
| **差分** | 区间"批量加"，最后统一求值 | 1109、1094 |
| **前缀和 + 哈希** | 统计"和为 k 的子数组个数" | 560 |

**差分是前缀和的逆运算**——前缀和是"把区间和变成两点之差"，差分是"把区间加变成两点修改"。

### 3. 下标约定要写清楚

本题用 **1-based 的前缀和**（`P[0]` 是哨兵，`P[i]` 对应前 `i` 个元素）。
写题时如果混用 0-based，`+1` 会到处出错。**选定一套，全题统一。**

### 4. 溢出

区间和可能超过 `int`（例如长度 $10^5$、元素 $10^4$ 时约 $10^9$，临界）。
**保险起见，前缀和数组用 `long long`。** 本题数据范围小，`int` 够用。
