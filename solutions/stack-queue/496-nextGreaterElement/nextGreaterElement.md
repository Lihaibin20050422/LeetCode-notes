# 496.nextGreaterElement(下一个更大元素 I)

## 题目
nums1 是 nums2 的子集。对 nums1 中每个元素，找出它在 nums2 中的**下一个更大元素**；不存在则返回 -1。

示例:
输入: nums1 = [4,1,2], nums2 = [1,3,4,2]
输出: [-1,3,-1]
解释: 4 后面没有更大的 → -1；1 的下一个是 3；2 后面没有 → -1

## 思路一：暴力 O(n·m)

对 nums1 里每个 x：
1. 先在 nums2 中找到 x 的位置
2. 从它右边开始扫，遇到的第一个比 x 大的就是答案

## 思路二：单调栈 O(n+m) ← 本题的正解

**关键观察：可以只扫描 nums2 一遍，用一个"单调递减栈"给每个元素提前算好答案。**

从左到右扫 nums2，栈里放"**还没遇到下一个更大元素**"的数（它们在栈里是**递减**的）：
- 新来一个 x：**只要栈顶 < x**，就说明栈顶（以及下面比 x 小的）的"下一个更大"就是 x
  → 记录 `map[栈顶] = x`，弹出它（可能连弹好几个）
- 然后把 x 压栈
- 扫描结束后，栈里剩下的元素都没有下一个更大元素

每个元素入栈一次、出栈一次 → O(m)；再用哈希表回答 nums1 的每个询问 → 总共 **O(n+m)**。

## 代码（单调栈）
```cpp
class Solution {
public:
    vector<int> nextGreaterElement(vector<int>& nums1, vector<int>& nums2) {
        unordered_map<int,int> nxt;   // 值 -> 它的下一个更大元素
        stack<int> st;                // 单调递减栈

        for(int x : nums2){
            while(!st.empty() && st.top() < x){
                nxt[st.top()] = x;    // x 就是栈顶的"下一个更大"
                st.pop();
            }
            st.push(x);
        }

        vector<int> ans;
        for(int x : nums1){
            ans.push_back(nxt.count(x) ? nxt[x] : -1);
        }
        return ans;
    }
};
```

## 复杂度

| 写法 | 时间 | 空间 |
|---|---|---|
| 暴力 | O(n·m) | O(1) |
| **单调栈** | **O(n+m)** | O(m) |

## 要点

### 1. 为什么"看到更大就弹出"
栈里存的是"**还没等到下一个更大值**"的数，且从上到下递减。
新来的 x 若比栈顶大，那**栈顶（及下面所有比 x 小的）的答案必然是 x**——因为 x 是它们遇到的第一个更大的数。

> 一句话：**栈里排队的，遇到比自己大的，就可以"结账"走人。**

### 2. 这又是一次"维护状态"
用栈维护"还在等的人"，而不是让每个元素都回头重新扫一遍。
**每个元素只进出一次**，所以是 O(m)。

### 3. 题目保证 nums1 ⊆ nums2
所以暴力里"先在 nums2 找到 x"一定找得到。没有这个保证的话，要加边界判断。
