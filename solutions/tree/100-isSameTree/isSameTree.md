# 100.isSameTree(相同的树)

## 题目
给你两棵二叉树的根节点 p 和 q，编写一个函数来检验这两棵树是否相同。
如果两个树在结构上相同，并且节点具有相同的值，则认为它们是相同的。

示例 1:
输入: p = [1,2,3], q = [1,2,3]
输出: true

示例 2:
输入: p = [1,2], q = [1,null,2]
输出: false

示例 3:
输入: p = [1,2,1], q = [1,1,2]
输出: false

## 思路

**递归同时遍历两棵树**：在同一个位置上，同时看 p 和 q 的对应结点，逐项判断：

1. 两个都空 → 相同（true）
2. 只有一个空 → 不同（false）
3. 都不空但值不同 → 不同（false）
4. 都不空且值相同 → 递归比较"左子树对左子树""右子树对右子树"

**本质就是：同时前序遍历两棵树，逐个结点比对。**

## 代码
```cpp
class Solution {
public:
    bool isSameTree(TreeNode* p, TreeNode* q) {
        if(p == nullptr && q == nullptr) return true;
        if(p == nullptr || q == nullptr) return false;
        if(p->val != q->val) return false;
        return isSameTree(p->left, q->left) && isSameTree(p->right, q->right);
    }
};
```

## 复杂度

- 时间：$O(n)$（$n$ 为较小那棵树的结点数，一旦不同就提前返回）
- 空间：$O(h)$（递归栈深度，$h$ 为树高）

## 要点

### 1. 三个判断的顺序不能换

```cpp
if(p == nullptr && q == nullptr) return true;    // ① 都空 → 相同
if(p == nullptr || q == nullptr) return false;   // ② 一空一不空 → 不同
if(p->val != q->val) return false;               // ③ 值不同 → 不同
```

- **必须先判空、再取值**——否则第③句会空指针解引用
- **①必须在②前面**——两个都空时，②的 `||` 条件也成立，会把"相同"误判成"不同"

### 2. ⚠️ 一个"看着聪明、其实是坑"的思路

**想法**：分别求出两棵树的**先序 + 中序序列**，两个序列都相同就说明树相同。

**这个思路是错的。** 因为：

> **"先序 + 中序唯一确定一棵二叉树"这个结论，前提是【元素互不相同】。**

**反例：**

| | 树 A：1 的**左**孩子是 1 | 树 B：1 的**右**孩子是 1 |
|---|---|---|
| 先序 | `1 1` | `1 1` |
| 中序 | `1 1` | `1 1` |

**两棵结构完全不同的树，先序和中序一模一样。**

（而且这个思路还更慢：要 O(n) 时间 **+ O(n) 空间** 存序列。）

### 3. 递归是"两棵树一起走"

```cpp
isSameTree(p->left, q->left) && isSameTree(p->right, q->right)
```

**不是"各走各的再比较"，而是"每一步都成对比较"。**
这是"树与树对比"这一类题的标准形态。
