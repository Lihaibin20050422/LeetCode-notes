# 150.evalRPN(逆波兰表达式求值)

## 题目
给你一个字符串数组 tokens，表示一个根据**逆波兰表示法（后缀表达式）**表示的算术表达式。
请你计算该表达式，返回一个表示表达式值的整数。

注意：
- 有效的算符为 `+`、`-`、`*`、`/`
- 两个整数之间的除法总是**向零截断**
- 表达式不含除以 0 的情况，输入均有效

示例:
输入: tokens = ["2","1","+","3","*"]
输出: 9
解释: 该算式转化为常见的中缀算术表达式为：((2 + 1) * 3) = 9

## 思路

**一个栈**。后缀表达式的求值规则非常机械：

- 遇到**数字** → 压栈
- 遇到**运算符** → 弹出两个数，运算，把结果压回去

**关键：弹出顺序！**
先弹出的是**右操作数**，后弹出的是**左操作数**：

```cpp
int a = st.top(); st.pop();   // a = 右操作数（后进先出）
int b = st.top(); st.pop();   // b = 左操作数
res = b - a;                  // 不是 a - b！
```

## 代码
```cpp
class Solution {
public:
    int evalRPN(vector<string>& tokens) {
        stack<int> st;
        for(string s : tokens){
            if(s == "+" || s == "-" || s == "*" || s == "/"){
                int a = st.top(); st.pop();   // 右操作数
                int b = st.top(); st.pop();   // 左操作数
                int res;
                if(s == "+")      res = b + a;
                else if(s == "-") res = b - a;   // 注意 b-a
                else if(s == "*") res = b * a;
                else              res = b / a;   // 注意 b/a
                st.push(res);
            }else{
                st.push(stoi(s));   // 字符串转 int
            }
        }
        return st.top();
    }
};
```

## 复杂度
- 时间：$O(n)$——每个 token 进出栈各一次
- 空间：$O(n)$——栈

## 要点

### 1. 弹出顺序是唯一的坑
栈是**后进先出**：`2 1 -` 里，先压 2、再压 1，所以先弹出的是 `1`（右操作数）。

> **减法、除法必须写 `b - a` / `b / a`**，写成 `a - b` 就全错了。
> 加法和乘法无所谓（交换律），所以很多人在这里"蒙混"过去，直到遇到减法才炸。

### 2. 除法是"向零截断"
C++ 的整数除法本身就是**向零截断**（`-7/2 == -3`），刚好符合题意，不用额外处理。

### 3. 这就是 408 的"后缀表达式求值"
DS 里用"栈 + 手写"实现过同一个算法。区别只是：
- DS：C 语言手写数组栈、字符/数字分开处理；
- LC：STL `stack` + `stoi` 转数字。

**同一套思想，换了个容器。**

### 4. 为什么后缀表达式不需要括号
因为在后缀式里，**运算符的位置已经蕴含了优先级**——每遇到一个运算符，它前面的两个操作数就是它的操作数。所以**栈顶的两个数永远就是当前运算所需的两个数**。
