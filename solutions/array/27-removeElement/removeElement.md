# 27.removeElement(移除元素)

## 题目
给你一个数组 nums 和一个值 val，你需要 原地 移除所有数值等于 val 的元素。元素的顺序可能发生改变。然后返回 nums 中与 val 不同的元素的数量。
假设 nums 中不等于 val 的元素数量为 k，要通过此题，您需要执行以下操作：
更改 nums 数组，使 nums 的前 k 个元素包含不等于 val 的元素。nums 的其余元素和 nums 的大小并不重要。
返回 k。。

## 思路

**双指针（快慢指针）**：和 26 题同一个套路——快指针 `i` 遍历数组，慢指针 `k` 记录"保留元素该放的位置"。

1. 慢指针 `k` 从 0 开始（注意：和 26 题不同，这里 `nums[0]` 也可能是 val，要过滤掉）
2. 快指针 `i` 从 0 开始遍历整个数组
3. 遇到 `nums[i] != val`，说明这个元素要保留，把它搬到 `k` 位置，`k` 前移：`nums[k++] = nums[i]`
4. 遇到 `nums[i] == val`，直接跳过（`i` 继续走，`k` 不动）
5. 遍历结束，`k` 就是"不等于 val 的元素个数"

用一个例子理解：`nums = [3, 2, 2, 3]`, `val = 3`

```
k=0
i=0: nums[0]==3（等于val）→ 跳过
i=1: nums[1]!=3（2）→ nums[0]=2, k=1
i=2: nums[2]!=3（2）→ nums[1]=2, k=2
i=3: nums[3]==3（等于val）→ 跳过
返回 k=2，前两个元素是 [2,2]
```

## 代码
```cpp
class Solution {
public:
    int removeElement(vector<int>& nums, int val) {
        int k=0;
        for(int i=0;i<nums.size();i++){
            if(nums[i]!=val){
                nums[k++]=nums[i];
            }
        }
        return k;
    }
};
```

## 复杂度

- 时间：$O(n)$，快指针 `i` 遍历一次数组
- 空间：$O(1)$，原地算法，只用了两个变量

## 要点

- **`k` 从 0 开始，和 26 题 `k` 从 1 开始的区别**：26 题第一个元素一定保留（因为数组有序，第一个元素不可能是"前面元素的重复"）；本题第一个元素可能是 val（要移除），所以 `k` 从 0 开始，遇到第一个非 val 才放到 `nums[0]`。这是两题最本质的区别。
- **`nums[k++] = nums[i]` 一句话干两件事**：赋值 + `k` 前移，快慢指针的经典写法。
- **为什么能原地覆盖**：`k` 永远 ≤ `i`，所以用 `nums[i]` 覆盖 `nums[k]` 时，覆盖掉的都是已经"处理过"的元素，不会丢失还没遍历到的数据。
- **和 26 题的共同点**：都是"快慢指针"，都是"快指针过滤、慢指针重写"，本质是同一个模板的两种变体。
