# 104.maxDepth(二叉树的最大深度)

## 题目
给定一个二叉树 root，返回其最大深度。
二叉树的最大深度是指从根节点到最远叶子节点的最长路径上的节点数。

示例 1:
输入: root = [3,9,20,null,null,15,7]
输出: 3

示例 2:
输入: root = [1,null,2]
输出: 2

## 思路

**递归**：一棵树的最大深度 = `max(左子树深度, 右子树深度) + 1`。

1. 空结点 → 返回 0
2. 否则 → `max(左, 右) + 1`

## 代码
```cpp
class Solution {
public:
    int maxDepth(TreeNode* root) {
        if(root == nullptr) return 0;
        int lh = maxDepth(root->left);
        int rh = maxDepth(root->right);
        return lh > rh ? lh + 1 : rh + 1;
    }
};
```

## 复杂度

- 时间：$O(n)$
- 空间：$O(h)$（递归栈深度）

## 要点

### 1. 这是"树上的递归计数"模板

```
f(空)   = 0
f(结点) = 合并( f(左), f(右) ) + 1
```

你在 DS 里写过的 `GetHeight` / `CountNode` / `CountLeafNode` 都是**同一个模板**——
**这题就是 `GetHeight` 换个名字。**

### 2. 和 LC 111（最小深度）是一对，但**不一样**

| | **104 最大深度** | **111 最小深度** |
|---|---|---|
| 空结点 | 0 | 0 |
| **单孩子** | **不用特判** | **必须特判** |
| 公式 | `max(lh,rh)+1` | 特判后 `min(lh,rh)+1` |

**104 之所以不用特判，是因为 `max(0, x) = x`**——空的那一边是 0，`max` 会自然忽略它。

**（详见 111 的题解：为什么 `min` 就不行。）**
