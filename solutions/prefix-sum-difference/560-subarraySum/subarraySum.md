# 560. 和为 K 的子数组

## 题目

给你一个整数数组 `nums` 和一个整数 `k`，统计并返回**和为 `k` 的连续子数组**的个数。

示例：`nums = [1,1,1], k = 2` → `2`

## 思路：前缀和 + 哈希表

**第一步：前缀和**

```
P[i] = a[0] + a[1] + ... + a[i-1]
子数组 (j+1 .. i) 的和 = P[i] - P[j]
```

**第二步：把"求和"变成"查差"**

我们想找：`P[i] - P[j] = k`
等价于：**`P[j] = P[i] - k`**

所以遍历到 `i` 时，只要问一句：**"之前出现过多少次 `P[i] - k`？"**

**第三步：用哈希表记次数**

```cpp
unordered_map<int, int> hash;   // 前缀和的值 -> 出现次数
hash[0] = 1;                    // 空前缀，代表"从下标 0 开始的子数组"
```

> 这是这道题最容易漏的一行。`hash[0] = 1` 表示"前缀和为 0 的情况出现过一次"，
> 这样 `P[i] == k`（即整个前缀本身就是答案）才能被统计到。

## 为什么是"先查后加"

```cpp
for (int i = 1; i <= n; i++) {
    int target = prefix[i] - k;
    if (hash.find(target) != hash.end()) {   // ① 先查
        ans += hash[target];
    }
    hash[prefix[i]]++;                        // ② 后加
}
```

**顺序不能反。**

如果先执行 `hash[prefix[i]]++` 再查，那么当 `k == 0` 时，会把自己也算进去——**相当于允许 `j == i`，即"空子数组"**，结果偏大。

> **先查后加 = 只允许 `j < i` = 子数组至少长度为 1。**

## 代码

```cpp
int subarraySum(vector<int>& nums, int k) {
    int n = nums.size();
    vector<int> prefix(n + 1, 0);
    for (int i = 0; i < n; i++) {
        prefix[i + 1] = prefix[i] + nums[i];
    }
    unordered_map<int, int> hash;
    hash[prefix[0]] = 1;
    int ans = 0;
    for (int i = 1; i <= n; i++) {
        int target = prefix[i] - k;
        if (hash.find(target) != hash.end()) {
            ans += hash[target];
        }
        hash[prefix[i]]++;
    }
    return ans;
}
```

## 复杂度

- 时间 $O(n)$：一次遍历，哈希均摊 $O(1)$
- 空间 $O(n)$：前缀和数组 + 哈希表

## 要点

### 1. 这和"两数之和"是同一个动作

| | 1. 两数之和 | **560. 和为 K** |
|---|---|---|
| 要找的 | `a + b = target` | `P[i] - P[j] = k` |
| 哈希里查的 | **`target - a`** | **`P[i] - k`** |
| 哈希存什么 | 元素值 → 下标 | **前缀和 → 出现次数** |

> **"不直接凑和，而去查差"——这是哈希表最核心的一个用法。**
> 你说是从两数之和想到的，**这个迁移非常准确**。

### 2. 为什么不能用滑动窗口

数组里**有负数**，窗口右扩不保证和变大、左缩不保证变小——**单调性不成立**，滑动窗口失效。

（对比 209 长度最小的子数组：全正数，才能用滑窗。）

> **凡是"子数组和"的题，先看有没有负数：**
> - 没有负数 → 滑动窗口 / 双指针
> - **有负数 → 前缀和 + 哈希**

### 3. 哈希存的是"次数"，不是"下标"

因为题目只问**有多少个**，不问"是哪几个"。存次数才能一次加完。

如果题目改成"找出所有子数组"，那哈希里就要存 `vector<int>` 的下标列表。

### 4. `hash[0] = 1` 的位置

写成 `hash[prefix[0]] = 1` 和 `hash[0] = 1` 等价（因为 `prefix[0] == 0`）。
**但用 `prefix[0]` 写，语义更清楚：这是"空前缀"。**

### 5. 边界

| 情况 | 结果 |
|---|---|
| `k = 0`，元素全为 0 | $n(n+1)/2$ 个 |
| `k` 比总和还大 | 0 |
| `k` 为负数 | 正常统计（前缀和可能为负） |
