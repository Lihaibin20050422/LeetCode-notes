# 69. x 的平方根

## 题目

给你一个非负整数 `x`，计算并返回 `x` 的算术平方根，**只保留整数部分**（向下取整）。
不使用任何内置指数函数和算符。$x$ 最大到 $2^{31}-1$。

## 思路：二分的对象不是数组，是"答案的取值范围"

这题没有数组，但答案是**单调**的：

> 若 $m^2 \le x$，那么 $1..m$ 全部可行；若 $m^2 > x$，那么 $m$ 及更大的全部不可行。

所以可以在 $[1, x]$ 上二分，找**最大的可行 m**。

用一个 `res` 记住"已经确认过的最大可行值"——这样二分结束时它就是要的答案，
不用担心最后停在哪个下标。

### 两个必须处理的细节

1. **别写 `mid * mid`**：`mid` 可能到 $2^{31}$，平方直接溢出。
   改成 **`mid <= x / mid`**（除法不溢出）。注意 `mid = 0` 的情况，所以 `low` 从 1 开始。
2. **`x = 0` 要能返回 0**：`low = 1 > high = 0`，循环不进，直接返回初值 `res = 0`。

## 代码

```cpp
int mySqrt(int x) {
    int low = 1;
    int high = x;
    int res = 0;                    // 已验证过的最大可行解
    while (low <= high) {
        int mid = low + (high - low) / 2;
        if (mid <= x / mid) {       // 除法比较，防溢出
            res = mid;              // mid 可行 → 记下来，再往右试
            low = mid + 1;
        } else {
            high = mid - 1;         // mid 太大 → 往左找
        }
    }
    return res;
}
```

## 复杂度

- 时间 $O(\log x)$
- 空间 $O(1)$

## 要点

### 1. 这是"二分答案"的入口

二分不止能搜数组，**只要答案具有单调性（可行/不可行有一条分界线），就能二分**。
这题的分界线是 $\sqrt{x}$：左边全可行，右边全不可行。

以后 875（爱吃香蕉的珂珂）、410（分割数组的最大值）都用这个思路。

### 2. 和 153 的对照：`left = mid` 必须配上"上取整"

69 也可以写成 153 那种风格：

```cpp
int low = 1, high = x;
while (low < high) {
    int mid = low + (high - low + 1) / 2;   // ← 上取整，不能少
    if (mid > x / mid) high = mid - 1;
    else                low = mid;
}
return low;
```

注意 `+1`。因为这里出现了 `low = mid`（保留 mid），
如果还用下取整，当区间只剩两个元素时 `mid == low`，区间不缩小 → 死循环。

> **规律：`left = mid` → mid 取上整；`right = mid` → mid 取下整。**
> 谁被保留，谁就不能再当 mid，否则原地打转。

### 3. 边界

- `x = 0` → 0（靠 `res` 初值兜住）
- `x = 1` → 1
- `x = 2` → 1
- `x = 2147483647` → **46340**（$46340^2 = 2147395600$，$46341^2 > x$）
