# 283. 移动零

## 题目

给定一个数组 `nums`，把所有 `0` 移到末尾，同时**保持非零元素的相对顺序**。
必须**原地**操作，不能复制数组。

示例：`[0,1,0,3,12]` → `[1,3,12,0,0]`

## 思路：快慢指针（读指针 + 写指针）

- `fast`：读指针，负责"看"每个元素；
- `slow`：写指针，指向**下一个非零元素该放的位置**。

遇到非零就把 `fast` 的值**换到** `slow` 的位置，然后 `slow++`；遇到零就跳过。

### `slow` 的不变式（一句话说清）

> **`[0, slow)` 区间里全是已经排好的非零元素，且保持原来的相对顺序。**

想清楚这句，这题就不会写错。

## 代码

```cpp
void moveZeroes(vector<int>& nums) {
    int slow = 0;
    for(int fast = 0; fast < nums.size(); fast++){
        if(nums[fast] == 0){
            continue;
        }
        int temp = nums[fast];
        nums[fast] = nums[slow];
        nums[slow] = temp;
        slow++;
    }
}
```

## 复杂度

- 时间 $O(n)$：每个元素看一次
- 空间 $O(1)$：原地

## 要点

### 1. 为什么用 `swap`，而不是直接赋值

如果写成 `nums[slow] = nums[fast]`：

- 当 `fast > slow` 时，`nums[slow]` 上原本可能还是**没处理过的非零数**（还没被 swap 到前面），直接赋值会**把它覆盖掉**。

`swap` 把两者交换，谁都不丢；而且 `fast == slow` 时交换自己等于没操作，**没有副作用**。

### 2. 它是"原地删除类"题目的同一模板

| 题 | `slow` 的含义 |
|---|---|
| 26. 删除有序数组中的重复项 | 下一个"不重复元素"该放的位置 |
| 27. 移除元素 | 下一个"保留元素"该放的位置 |
| **283. 移动零** | 下一个"非零元素"该放的位置 |

> **凡是"原地保留一部分、丢掉/挪走另一部分"，都是快慢指针 + 写指针。**

### 3. 为什么不用"删掉 0 再补 0"

逻辑上可行，但需要额外操作统计零的个数，而且容易写成两遍扫描。**一遍扫描、一次交换**是最干净的写法。
