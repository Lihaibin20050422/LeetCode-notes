# 118. 杨辉三角

## 题目

给定行数 `numRows`，返回杨辉三角的前 `numRows` 行。

示例：`numRows = 5` →
```
[[1],
 [1,1],
 [1,2,1],
 [1,3,3,1],
 [1,4,6,4,1]]
```

## 思路：逐行生成，中间项来自上一行

每一行：

- **首尾一定是 1**
- **中间第 `j` 项 = 上一行第 `j-1` 项 + 第 `j` 项**

```cpp
row[j] = res[i - 1][j - 1] + res[i - 1][j];
```

### 一个小技巧：整行先填 1

```cpp
vector<int> row(i + 1, 1);      // 整行初始化为 1
for (int j = 1; j < i; j++) {   // 只处理中间
    row[j] = res[i - 1][j - 1] + res[i - 1][j];
}
```

**首尾的 1 就不用特判了**——初始化时已经填好。这是模拟题里最常见的“省边界”手法。

## 代码

```cpp
vector<vector<int>> generate(int numRows) {
    if (numRows == 0) {
        return {};
    }

    vector<vector<int>> res;
    for (int i = 0; i < numRows; i++) {
        vector<int> row(i + 1, 1);
        for (int j = 1; j < i; j++) {
            row[j] = res[i - 1][j - 1] + res[i - 1][j];
        }
        res.push_back(row);
    }
    return res;
}
```

## 复杂度

- 时间 $O(n^2)$：总共生成 $\frac{n(n+1)}{2}$ 个数
- 空间 $O(n^2)$：返回结果本身占这么多（不算额外空间）

## 要点

### 1. 内层循环的范围

```cpp
for (int j = 1; j < i; j++)   // 是 j < i，不是 j <= i
```

第 `i` 行下标是 `0..i`，**首尾（0 和 i）已经是 1，只需要算 `1..i-1`。**

写成 `j <= i` 会 `row[i+1]` 越界。

### 2. 这个递推式就是组合数公式

杨辉三角第 `i` 行第 `j` 项 = $C_i^j$，而

$$C_i^j = C_{i-1}^{j-1} + C_{i-1}^{j}$$

**这就是杨辉三角的本质。** 408 的概率/组合题里，这个递推经常出现（比如二项分布）。

> **用加法递推算组合数，比直接用阶乘公式好**——不会溢出、不用除法。

### 3. 空间可以省到 O(n)

如果只需要**第 k 行**（LeetCode 119），可以从后往前更新同一行：

```cpp
for (int j = i - 1; j >= 1; j--) row[j] += row[j - 1];
```

**倒着更新**，就不会用到已经被覆盖的值。这是“滚动数组”的经典用法。

### 4. 边界

| 输入 | 输出 |
|---|---|
| `0` | `[]`（题目保证 ≥1，但写上更稳） |
| `1` | `[[1]]` |
