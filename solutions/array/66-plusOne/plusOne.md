# 66.plusOne(加一)

## 题目
给定一个由整数组成的非空数组所表示的非负整数，在该数的基础上加一。
最高位数字存放在数组的首位，数组中每个元素只存储单个数字。
你可以假设除了整数 0 之外，这个整数不会以零开头。

示例 1:
输入: digits = [1,2,3]
输出: [1,2,4]

示例 2:
输入: digits = [4,3,2,1]
输出: [4,3,2,2]

示例 3:
输入: digits = [9]
输出: [1,0]

## 思路

**从最低位（数组末尾）向前遍历，模拟加法进位**：

1. 从 `i = n-1` 开始向前遍历
2. 当前位 `!= 9` → 加 1 直接返回（因为 +1 不会产生进位）
3. 当前位 `== 9` → 置 0，继续向前（9+1=10，本位 0，进位 1）
4. 遍历完都没返回 → 说明所有位都是 9（如 999），需要最高位补 1（1000）

用一个例子理解：`digits = [1,9,9]`

```
i=2: digits[2]=9 → 置0 → [1,9,0]
i=1: digits[1]=9 → 置0 → [1,0,0]
i=0: digits[0]=1≠9 → +1=2 → [2,0,0]，返回
```

## 代码
```cpp
class Solution {
public:
    vector<int> plusOne(vector<int>& digits) {
        for(int i = digits.size()-1; i >= 0; i--){
            if(digits[i] != 9){
                digits[i] += 1;
                return digits;
            }
            digits[i] = 0;
        }
        // 全部是9：如 999 -> 1000
        digits.push_back(0);
        for(int i = digits.size()-1; i >= 1; i--){
            digits[i] = digits[i-1];
        }
        digits[0] = 1;
        return digits;
    }
};
```

## 复杂度

- 时间：$O(n)$，最多遍历一次数组
- 空间：$O(1)$，原地操作（全 9 时扩容 1 位，仍是 $O(1)$ 额外空间）

## 要点

- **只有 9 会触发进位**：`9+1=10` 要进位，其他数字 `+1` 都不会进位。所以核心是"遇 9 置 0 继续，遇非 9 加 1 返回"。
- **全 9 是最坏情况**：`999+1=1000`，长度 +1，需要扩容。你写的 `push_back(0) + 右移 + 首位置1` 是对的，但可以简化——因为右移前所有位都已经置成 0 了，右移等于没动，直接写 `digits[0]=1; digits.push_back(0);` 即可。
- **为什么必须从后往前**：进位是从低位向高位传递的，必须从最低位（数组末尾）开始。
