# 438. 找到字符串中所有字母异位词

## 题目

给定两个字符串 `s` 和 `p`，找到 `s` 中所有 `p` 的**字母异位词**的起始索引。
异位词：字母种类和数量完全相同，只是顺序不同。

示例：`s = "cbaebabacd", p = "abc"` → `[0, 6]`

## 思路：固定长度窗口 + 频率数组

窗口长度**恒等于 `p` 的长度 `m`**，所以不需要判断"什么时候缩"——每轮固定右移一格：

1. 先统计 `p` 的字符频率 `cnt_p`，以及 `s` 前 `m` 个字符的频率 `cur`；
2. 比较两个频率数组，相等就记录下标 0；
3. 之后每滑一格：**左端字符移出（--），右端新字符移入（++）**，再比较一次。

### 为什么用频率数组，而不是排序

判断两个串是否互为异位词，有两种方式：

| 方式 | 单次判定 | 说明 |
|---|---|---|
| 各自排序后比较 | $O(m\log m)$ | 每滑一格都排序，太慢 |
| **频率数组相等** | $O(26)$ | 滑动时还能 O(1) 更新 |

窗口滑动时**只删一个字符、只加一个字符**，频率数组可以增量维护——这是关键。

## 代码

```cpp
vector<int> findAnagrams(string s, string p) {
    vector<int> res;
    int n = (int)s.size(), m = (int)p.size();
    if (m > n) return res;

    vector<int> cnt_p(26, 0), cur(26, 0);
    for (int i = 0; i < m; i++) cnt_p[p[i] - 'a']++;
    for (int i = 0; i < m; i++) cur[s[i] - 'a']++;

    if (cnt_p == cur) res.push_back(0);

    for (int left = 1; left <= n - m; left++) {
        cur[s[left - 1] - 'a']--;          // 左端滑出
        cur[s[left + m - 1] - 'a']++;      // 右端滑入
        if (cnt_p == cur) res.push_back(left);
    }
    return res;
}
```

## 复杂度

- 时间 $O(26 \cdot (n-m+1)) = O(n)$：每个窗口比较 26 次，26 是常数
- 空间 $O(26)$

## 要点

### 1. 三种滑动窗口，正好凑齐

| 题 | 窗口长度 | 每轮的触发条件 |
|---|---|---|
| 209. 长度最小的子数组 | 可变 | `sum >= target` 就缩 |
| 3. 无重复最长子串 | 可变 | 遇重复就跳左端 |
| **438. 字母异位词** | **固定 = m** | **每滑一格就判一次** |

**固定窗口没有"何时缩"的问题**，只剩"进一个、出一个、比一次"。

### 2. 优化：用 `diff` 把比较降到 $O(1)$

现在每次 `cnt_p == cur` 都要扫 26 格。维护"有多少个位置不相等"：

```cpp
int diff = 0;
for (int i = 0; i < 26; i++) if (cnt_p[i] != cur[i]) diff++;

// 某个字符 c 出窗：
if (cur[c] == cnt_p[c]) diff++;   // 原本相等，改完就不等了
cur[c]--;
if (cur[c] == cnt_p[c]) diff--;   // 减完恰好又相等

// 进窗同理；每轮只需 if (diff == 0)
```

从 $O(26n)$ 变成严格 $O(n)$。不是必须，但说明你真的想清楚了"状态怎么维护"。

### 3. 边界

| 情况 | 处理 |
|---|---|
| `m > n` | 直接返回空 |
| `m == n` | 循环 `left <= 0` 不进，只判下标 0 |
| 大小写 | 本题只含小写字母，`p[i]-'a'` 不会越界 |
