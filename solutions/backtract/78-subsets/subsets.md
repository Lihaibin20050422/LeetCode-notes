# 78. 子集

## 题目

给你一个**互不相同**的整数数组 `nums`，返回它的所有子集（幂集）。解集中不能包含重复的子集。

示例：`[1,2,3]` → `[[],[1],[2],[3],[1,2],[1,3],[2,3],[1,2,3]]`

## 思路：每个元素"选 / 不选"，长成一棵二叉决策树

对每个下标 `idx`，只做两个决定：

- **不选** `nums[idx]` → 递归 `idx + 1`
- **选** `nums[idx]` → 把元素压入 `path`，递归 `idx + 1`，**返回后弹出**

走到 `idx == n` 就是一个叶子，此时 `path` 里就是一个完整的子集。

```
                        []
             不选1 /          \ 选1
                 []            [1]
           不选2/  \选2     不选2/  \选2
             []    [2]       [1]   [1,2]
          ...
```

**这棵树有 $2^n$ 个叶子，正好对应 $2^n$ 个子集。**

## 代码

```cpp
vector<vector<int>> ans;
vector<int> path;

void backtrack(int idx, vector<int>& nums) {
    if (idx == (int)nums.size()) {
        ans.push_back(path);
        return;
    }
    //分支1：不选nums[idx]
    backtrack(idx + 1, nums);
    //分支2：选nums[idx]
    path.push_back(nums[idx]);
    backtrack(idx + 1, nums);
    path.pop_back(); //回溯
}

vector<vector<int>> subsets(vector<int>& nums) {
    ans.clear();
    path.clear();
    backtrack(0, nums);
    return ans;
}
```

## 复杂度

- 时间 $O(n \cdot 2^n)$：$2^n$ 个子集，每个拷贝一次是 $O(n)$
- 空间 $O(n)$：递归栈 + `path`

## 要点

### 1. 这就是"解空间树"的标准例子

你说的没错——这棵二叉决策树，正是**回溯法**和**分支限界法**教科书里的**子集树**。

| | 回溯法 | 分支限界法 |
|---|---|---|
| 在树上怎么搜 | **DFS**（递归） | **BFS / 优先队列** |
| 什么时候剪枝 | 约束不满足就退回 | **限界函数：当前代价 > 已知最优 → 剪掉** |
| 目标 | 找任意解 / 所有解 | 找**最优解** |

**本题是这棵树最干净的形态**：所有解都要，没有约束、没有限界，所以**不需要剪枝**。

> 记住这张表：**78 是骨架，剪枝是后来的事。**

### 2. `pop_back()` 才是"回溯"两个字

```cpp
path.push_back(nums[idx]);   // 做选择
backtrack(idx + 1, nums);    // 递归
path.pop_back();             // 撤销选择 ← 关键
```

**如果不撤销，`path` 会一直往后累积，第二个分支拿到的就是脏数据。**

一句话：**"做选择 → 递归 → 撤销选择"**，这是所有回溯题的共同骨架。

### 3. 同一个问题，还有第二种写法

用 `for` 循环枚举"下一个选谁"：

```cpp
void dfs(int start, vector<int>& nums) {
    ans.push_back(path);                 // 每个结点都是一个解
    for (int i = start; i < nums.size(); i++) {
        path.push_back(nums[i]);
        dfs(i + 1, nums);
        path.pop_back();
    }
}
```

**两种写法结果一样。** 区别：

| | 选/不选 | for + start |
|---|---|---|
| 树的形状 | **二叉**子集树 | 多叉树 |
| 和教材解空间树对照 | **一一对应** | 不太直观 |
| 适合 | 每个元素独立决策 | **组合类（77、39）** |

### 4. 全局变量的坑

`ans` / `path` 是全局的，**所以 `subsets()` 里必须 `clear()`**。
否则同一份程序里调用两次，第二次的结果会带着第一次的残留。LeetCode 上的全局变量尤其要注意这一点。

### 5. 剪枝是怎么加进来的

| 题 | 剪枝 |
|---|---|
| 78 子集 | 不需要 |
| 77 组合 | `剩余元素不够 k 个` → 提前 `break` |
| 39 组合总和 | `sum > target` → 提前 `break` |
| 90 子集 II | 排序后跳过同一层的重复元素 |
