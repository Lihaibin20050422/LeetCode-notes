# 11. 盛最多水的容器

## 题目

给定一个长度为 n 的数组 `height`，第 i 条线的高度为 `height[i]`。选出两条线，与 x 轴围成一个容器，求能装的最大水量。

面积 = `min(height[l], height[r]) × (r − l)`

示例：`[1,8,6,2,5,4,8,3,7]` → `49`

## 思路：相向双指针，**移动短的那一边**

两个指针放在两端，每次算出当前面积，然后：

- `height[left] < height[right]` → `left++`
- 否则 → `right--`

## 为什么移动短边是安全的（这道题必须能证）

设当前窗口 `[l, r]`，且 `h[l] < h[r]`，当前面积 `S = h[l] × (r − l)`。

**考虑所有以 `l` 为左端点的窗口 `[l, r']`（`r' ≤ r`）：**

1. 宽度 `r' − l ≤ r − l`；
2. 高度 `min(h[l], h[r']) ≤ h[l]`。

两者相乘：

```
S' ≤ h[l] × (r − l) = S
```

> **⇒ 以 `l` 为左端点的所有窗口，都不可能比当前这个更好。**
> **所以 `l` 可以被整条排除。**

这不是“试一试”，是**排除了一个端点所对应的所有可能**。每轮排除一个端点，所以最多 n 轮。

**注意措辞**：不是“移动高的那一边长度会缩小”这么简单——是**高度被短边卡死了**，再怎么挪右边，`min` 也超不过 `h[l]`，而宽度只会更小。

## 代码

```cpp
int maxArea(vector<int>& height) {
    int left = 0;
    int right = height.size() - 1;
    int maxWater = 0;
    while(left < right){
        int h = min(height[left], height[right]);
        int w = right - left;
        maxWater = max(maxWater, h * w);
        if(height[left] < height[right]){
            left++;
        }else{
            right--;
        }
    }
    return maxWater;
}
```

## 复杂度

- 时间 $O(n)$：每个位置最多被排除一次
- 空间 $O(1)$

## 要点

### 1. 两边相等时，动哪边都行

`h[l] == h[r]` 时，动任意一边，两边都会少掉一个“当前短边”——**两种情况结果一样**，代码里走 `else` 即可。

### 2. 和 167 的对比

| | 167 两数之和 | **11 盛水** |
|---|---|---|
| 排除的是 | **一个元素** | **一个端点对应的所有窗口** |
| 依据 | 和的大小 | 面积的**短板效应** |
| 共同点 | 每一步都能证明“丢掉它不漏答案” | 同 |

> **双指针的完整论证，永远是两步：① 说明丢掉它不会漏；② 所以可以动。**
> 只说“感觉动短的更好”，在面试和复试里是会被追问的。

### 3. 暴力解为什么不行

暴力枚举 `(l, r)` 是 $O(n^2)$，$n = 10^5$ 时会超时。双指针把“枚举两个端点”变成“每轮排除一个端点”。

### 4. 溢出

本题 $height \le 10^4$、$n \le 10^5$，`h * w ≤ 10^9`，`int` 够用。
若数据更大，改成 `long long` 计算面积。
