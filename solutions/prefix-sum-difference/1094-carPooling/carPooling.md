# 1094. 拼车

## 题目

`trips[i] = [numPassengers, from, to]` 表示：在 `from` 站上 `numPassengers` 人，在 `to` 站下车。
车辆容量为 `capacity`，判断能否把所有乘客都送完（任何时刻车上人数不超过容量）。

示例：`trips = [[2,1,5],[3,3,7]], capacity = 4` → `false`

## 思路：差分数组（站点当坐标）

站点编号 `0..1000`，**值域小，直接开数组**，不需要离散化。

```cpp
diff[from] += num;
diff[to]   -= num;    // 注意：是 to，不是 to + 1
```

再对 `diff` 求前缀和，就是每个站点的车上人数。

## 关键：这道题是**左闭右开**区间

> **乘客在 `to` 站下车，意味着 `to` 站时他已经不在车上了。**
> **所以这条"占用"是 `[from, to)` —— 含左端，不含右端。**

这就是为什么减在 `diff[to]` 而不是 `diff[to + 1]`。

### 和 1109 对照着记（这是全题最重要的一点）

| 题 | 区间语义 | 差分怎么改 |
|---|---|---|
| **1109 航班预订** | `[first, last]`**闭区间** | `diff[last + 1] -= v` |
| **1094 拼车** | `[from, to)`**左闭右开** | **`diff[to] -= v`** |

> **写差分题前，必须先用一句话说清楚：这个区间含不含右端点。**
> 说错了，结果就整体偏移一位——**这就是你一开始 WA 的原因。**

### 为什么这题的右端点是开的

公交车在 `to` 站：**先下客，再上客**。

```
站 5：trip A 的 2 人下车 → 车上剩 0 → trip B 的 3 人上车 → 峰值 3
```

所以 `[[2,1,5],[3,5,7]]` 在 `capacity = 3` 时是合法的。**如果错写成 `diff[to+1]`，会算成 5，误判为 false。**

## 代码

```cpp
bool carPooling(vector<vector<int>>& trips, int capacity) {
    vector<int> diff(1001, 0);
    for (int i = 0; i < (int)trips.size(); i++) {
        int num = trips[i][0];
        int l = trips[i][1];
        int r = trips[i][2];
        diff[l] += num;
        diff[r] -= num;          // [l, r) 左闭右开
    }
    int cur = 0;
    for (int i = 0; i < 1001; i++) {
        cur += diff[i];
        if (cur > capacity) {
            return false;
        }
    }
    return true;
}
```

## 复杂度

- 时间 $O(n + 1000)$
- 空间 $O(1000)$（与站点值域有关）

## 要点

### 1. 数组为什么开 1001

题目约束 `0 ≤ from < to ≤ 1000`，最大下标是 **1000**，所以开 `1001` 个位置刚好。

> 注意和 1109 的区别：1109 开 `n + 2` 是为了防 `r + 1` 越界；**这题根本不用 `r + 1`**。

### 2. 边求前缀和边判断

不需要先算出完整数组再检查——**前缀和的每一步就是"某个站点的车上人数"，边累加边比较即可**，提前 `return false` 还能省时间。

### 3. 另一种写法：排序 + 事件扫描

把所有 "上车 +num" 和 "下车 -num" 做成事件，按站点排序，扫一遍累加。

- 优点：站点值域很大时也能用（不用开大数组）
- 缺点：要排序，$O(n \log n)$

**值域小用差分，值域大用事件扫描。**

### 4. 一个通用检查清单（差分三问）

1. **区间是闭还是半开？** → 决定减在 `r` 还是 `r + 1`
2. **右端点会不会越界？** → 决定数组开 `n + 1` 还是 `n + 2`
3. **下标从 0 还是 1 开始？** → 决定结果数组怎么映射
