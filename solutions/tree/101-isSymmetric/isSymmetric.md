# 101.isSymmetric(对称二叉树)

## 题目
给你一个二叉树的根节点 root，检查它是否轴对称。

示例 1:
输入: root = [1,2,2,3,4,4,3]
输出: true

示例 2:
输入: root = [1,2,2,null,3,null,3]
输出: false

## 思路

**成对递归（两个指针同时走）**：判断 root 的**左子树和右子树是否互为镜像**。

"互为镜像"的定义是：

- 两个结点的值相同
- **左结点的左孩子** 和 **右结点的右孩子** 互为镜像
- **左结点的右孩子** 和 **右结点的左孩子** 互为镜像

（注意后两条是**交叉配对**的——这就是"镜像"的含义。）

写一个辅助函数 `check(p, q)`：判断"以 p、q 为根的两棵子树是否互为镜像"。

1. p、q 都空 → 镜像 ✓
2. 只有一个空 → 不镜像 ✗（**结构不同**）
3. 值不同 → 不镜像 ✗
4. 值相同 → `check(p->left, q->right) && check(p->right, q->left)`

主函数：空树返回 true，否则 `check(root->left, root->right)`。

## 代码
```cpp
class Solution {
public:
    bool isSymmetric(TreeNode* root) {
        if(root == nullptr) return true;
        return check(root->left, root->right);
    }

    bool check(TreeNode* p, TreeNode* q){
        if(!p && !q) return true;
        if(!p || !q) return false;
        return (p->val == q->val)
               && check(p->left, q->right)
               && check(p->right, q->left);
    }
};
```

## 复杂度

- 时间：$O(n)$
- 空间：$O(h)$（递归栈深度，$h$ 为树高）

## 要点

### 1. ⚠️ 一个"看着对、其实有坑"的思路

**想法**：左子树按"**根左右**"遍历得到一个序列，右子树按"**根右左**"（镜像顺序）遍历得到另一个序列；
如果两个序列相同 → 对称。

**这个思路是错的。反例：**

```
        1
       / \
      2   2
     /   /
    3   3
```

- 左子树按 **根左右**：`2, 3` → `[2, 3]`
- 右子树按 **根右左**：根2 → 右孩子空 → 左孩子3 → `[2, 3]`

**两个序列一模一样，但这棵树不对称。**

（镜像要求：右边那个 2 应该带**右**孩子 3，而它带的是**左**孩子。）

**根因**：**遍历序列丢失了"结构信息"**——只有一个孩子时，序列里看不出它是左还是右。

### 2. 递归版为什么没这个坑

```cpp
if (!p || !q) return false;          // ← 这一句抓住了"结构不同"
```

**它不是"各走各的再比序列"，而是"每一步都成对比较"**——
所以"左孩子是 3 vs 右孩子是空"这种情况，立刻就被判错了，结构信息一点没丢。

### 3. 同一个坑，两天内出现了两次

| | LC 100（相同的树）| LC 101（对称二叉树）|
|---|---|---|
| 想法 | 先序 + 中序相同 → 树相同 | 根左右 + 根右左相同 → 对称 |
| 同一个坑 | **遍历序列丢失结构信息** | **遍历序列丢失结构信息** |
| 正解 | **成对递归比较** | **成对递归比较** |

> **规律：凡是"两棵树 / 两个结点是否满足某种关系"的题——不要比较遍历序列，要"成对递归"。**
> **因为序列是"一维"的，而树的关系是"二维"的。**

### 4. "成对递归"是你之前没写过的递归形态

你之前写的递归都是"**单指针**"的（前中后序遍历、求树高、求结点数）——只在一棵子树上往下走。

**而这题是"两个指针同时递归"**：

```cpp
check(p->left, q->right)     // p 往左下、q 往右下 —— 两个指针一起走
check(p->right, q->left)     // 交叉配对
```

**第一次遇到要想一下很正常**；记住这个形态之后，572、951 都是它。
