# 77. 组合

## 题目

给定两个整数 `n` 和 `k`，返回 `1..n` 中所有可能的 `k` 个数的组合。

示例：`n = 4, k = 2` → `[[1,2],[1,3],[1,4],[2,3],[2,4],[3,4]]`

## 思路：多叉树 + `start` 参数 + 剪枝

和 78（子集）的区别：

| | 78 子集 | **77 组合** |
|---|---|---|
| 树的形状 | **二叉**（每元素选/不选） | **多叉**（下一个选谁） |
| 结束条件 | 走到叶子（`idx == n`） | **`path.size() == k`** |
| 是否去重 | 天然不重复 | **需要 `start` 参数** |
| 剪枝 | 不需要 | **需要** |

### 为什么需要 `start`

组合**不关心顺序**：`[1,2]` 和 `[2,1]` 是同一个组合。

所以每层只能从**上一个选过的数之后**继续选——这就是 `start` 参数的作用。
没有它，就会生成 `[1,2]` 和 `[2,1]` 两份。

### 剪枝怎么推出来的

设当前已经选了 `path.size()` 个，还需要 `k - path.size()` 个。

从 `i` 到 `n` 一共有 `n - i + 1` 个数可选，要凑够需要的个数：

```
n - i + 1 >= k - path.size()
        i <= n - (k - path.size()) + 1
```

**这就是循环上界的来历。** 超过它的 `i` 根本凑不满，走了也是死路。

举个例子：`n = 4, k = 2`，第一层需要 2 个，从 `i` 到 4 只有 `4 - i + 1` 个。

- `i = 3` → 还剩 `3,4` 两个，够
- `i = 4` → 只剩 `4` 一个，**不够 → 剪掉**

## 代码

```cpp
vector<vector<int>> result;
vector<int> path;

void backtrack(int n, int k, int start) {
    if (path.size() == k) {
        result.push_back(path);
        return;
    }

    for (int i = start; i <= n - (k - path.size()) + 1; i++) {
        path.push_back(i);
        backtrack(n, k, i + 1);
        path.pop_back();
    }
}

vector<vector<int>> combine(int n, int k) {
    result.clear();
    path.clear();
    backtrack(n, k, 1);
    return result;
}
```

## 复杂度

- 时间 $O\binom{n}{k} \times k$：$\binom{n}{k}$ 个组合，每个拷贝 $k$ 个元素
- 空间 $O(k)$：递归栈 + `path`

## 要点

### 1. 两种回溯模板的选择

| | 选/不选（78） | **for + start（77）** |
|---|---|---|
| 循环写法 | 每个元素两个分支 | **每层一个 for** |
| 天然顺序 | 不需要处理 | **靠 `start` 保证递增** |
| 适合 | 子集、划分 | **组合、排列、N 皇后** |

**从这题开始，`for + start` 会是你用得更多的那一种。**

### 2. 剪枝不是"优化"，是"少走死路"

不剪枝也能出正确答案，只是会走一堆凑不满的分支。

> **剪枝的意义：提前知道"这条路走到黑也没有解"，就别走了。**

判断依据永远是**"剩余可选数量" vs "还需要选的数量"**。

### 3. 终止条件的写法

```cpp
if (path.size() == k) { result.push_back(path); return; }
```

**写 `path.size() == k` 而不是 `>= k`**——正常递归永远不会超过 k，写 `==` 更清晰地表达"恰好选够"。

### 4. 一个警告

`path.size()` 是 `size_t`，和 `int k` 比较会触发符号警告。本题 `k` 非负，结果不受影响，但习惯上可以写 `(int)path.size() == k`。
