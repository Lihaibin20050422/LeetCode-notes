# 111.minDepth(二叉树的最小深度)

## 题目
给定一个二叉树 root，找出其最小深度。
最小深度是从根节点到最近叶子节点的最短路径上的节点数量。

示例 1:
输入: root = [3,9,20,null,null,15,7]
输出: 2

示例 2:
输入: root = [1,null,2]
输出: 2

## 思路

**递归 + 单孩子特判**：

- 空结点 → 0
- **左空**（只有右孩子）→ 只能走右边：`minDepth(root->right) + 1`
- **右空**（只有左孩子）→ 只能走左边：`minDepth(root->left) + 1`
- 两个孩子都在 → `min(左, 右) + 1`

## 代码
```cpp
class Solution {
public:
    int minDepth(TreeNode* root) {
        if(root == nullptr) return 0;
        if(root->left == nullptr)  return minDepth(root->right) + 1;
        if(root->right == nullptr) return minDepth(root->left) + 1;
        int lh = minDepth(root->left);
        int rh = minDepth(root->right);
        return lh < rh ? lh + 1 : rh + 1;
    }
};
```

## 复杂度

- 时间：$O(n)$
- 空间：$O(h)$

## 要点

### 1. ⚠️ 本题唯一的难点：**不能**直接写 `min(lh, rh) + 1`

**"最小深度"的终点必须是【叶子】**（左右都空的结点）——**一条路径不能在半路断掉。**

**反例**：`1` 只有右孩子 `2`

```
    1
     \
      2
```

| 写法 | 结果 |
|---|---|
| `min(minDepth(null), minDepth(2)) + 1` = `min(0,1)+1` | **1** ✗（实际最小深度是 2）|
| **单孩子特判** | 左空 → `minDepth(2)+1 = 2` ✓ |

### 2. 为什么 104 不用特判、111 必须特判

关键在 **`0` 这个"空子树返回值"对 `max` 和 `min` 的影响完全不同**：

| | 空子树（值 0）的影响 |
|---|---|
| `max(0, x)` | **不影响**——0 是最小的，取最大值时取不到它 |
| `min(0, x)` | **直接把答案拉成 0** |

> **一句话：`max` 对 0 天然免疫；`min` 对 0 极其敏感。**

**——这就是"最大深度是模板题、最小深度是陷阱题"的根本原因。**

### 3. 一个可迁移的警觉

**变体题的关键，不是"改符号"，是"改了什么前提"。**

104 → 111，表面只是"`max` 改成 `min`"；但 `min` 和 `max` 对"空子树"的性质**相反**——
**所以光改符号不够，还得加特判。**

> **遇到"这是那道题的变体"时，先停一下问自己：
> "它改了什么？这个改动会不会影响边界情况？"**

（而不是"照着原题改个符号就交"。）
