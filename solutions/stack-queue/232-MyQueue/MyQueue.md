# 232.MyQueue(用栈实现队列)

## 题目
请你仅使用两个栈实现先入先出队列。队列应当支持一般队列支持的所有操作：
- `void push(int x)` 将元素 x 推到队列的末尾
- `int pop()` 从队列的开头移除并返回元素
- `int peek()` 返回队列开头的元素
- `boolean empty()` 如果队列为空返回 true，否则返回 false

示例:
输入: ["MyQueue","push","push","peek","pop","empty"] [[],[1],[2],[],[],[]]
输出: [null,null,null,1,1,false]

## 思路

**两个栈：s1 负责"入"，s2 负责"出"。**

- `push(x)`：`s1.push(x)`
- `pop() / peek()`：队列头 = **最早入队**的元素。把 s1 全部倒入 s2，**顺序就反过来了**——s2 的栈顶正好是队头：
  1. **只有当 s2 为空时**，才把 s1 全部倒入 s2
  2. 从 s2 取栈顶（= 队头）

## 代码（最优：懒汉法）
```cpp
class MyQueue {
    stack<int> s1, s2;   // s1 入栈，s2 出栈
public:
    void push(int x) { s1.push(x); }

    int pop() {
        if(s2.empty()){
            while(!s1.empty()){      // 只在 s2 空时补一次货
                s2.push(s1.top());
                s1.pop();
            }
        }
        int res = s2.top();
        s2.pop();
        return res;
    }

    int peek() {
        if(s2.empty()){
            while(!s1.empty()){
                s2.push(s1.top());
                s1.pop();
            }
        }
        return s2.top();
    }

    bool empty() { return s1.empty() && s2.empty(); }
};
```

## 复杂度
- `push`：O(1)
- `pop` / `peek`：**均摊 O(1)**（每个元素一生只被搬一次，s2 空了才补充）
- 空间：O(n)

## 要点

### 1. 关键：s2 **只倒一次，不倒回去**

每个元素的一生只有两次搬运：**进 s1 → 倒进 s2 → 出**。总共 O(n)，均摊到每次操作就是 **O(1)**。

### 2. 对照"朴素写法"

一种朴素写法是：**每次 pop/peek 都 s1→s2、再 s2→s1 倒回来**。
它是**正确的**，但每次操作都是 **O(n)**——因为它把**同一批元素的搬运，重复做了无数遍**。

这正是那个通用招式：

> **把"重复计算"，换成"维护状态"。**
>
> 让 s2 常驻当"输出缓冲区"，只在它空了的时候补一次货——这就是"维护状态"。

### 3. 为什么"倒进 s2 顺序就反了"
栈是 LIFO：s1 依次压 1、2、3，从 s1 弹出是 3、2、1；再压进 s2，s2 弹出是 1、2、3——**恰好是队头先出**。
这正是两个栈能"冒充"队列的原因。
