# 1109. 航班预订统计

## 题目

有 `n` 个航班（编号 `1..n`），`bookings[i] = [first, last, seats]` 表示从 `first` 到 `last`（含）每个航班预订了 `seats` 个座位。
返回长度为 `n` 的数组，表示每个航班的**总预订量**。

示例：`n = 5, bookings = [[1,2,10],[2,3,20],[2,5,25]]` → `[10,55,45,25,25]`

## 思路：差分数组

**差分是前缀和的逆运算**：

| | 前缀和 | **差分** |
|---|---|---|
| 处理什么 | **区间求和** | **区间加** |
| 核心动作 | `P[i+1] = P[i] + a[i]` | **`d[l] += v; d[r+1] -= v`** |
| 得到答案 | 直接查 `P` | **对 `d` 求一遍前缀和** |

### 为什么这样是对的

一次区间加 `[l, r]` 加 `v`，只需要改**两个位置**：

```
d[l]   += v      ← 从这里开始，后面的前缀和都多了 v
d[r+1] -= v      ← 从这里开始，把多加的 v 减掉
```

对这些 `d` 求前缀和，就"还原"成了每个位置被加了多少。

> **区间操作从 O(区间长度) 降到 O(1)。**

## 代码

```cpp
vector<int> corpFlightBookings(vector<vector<int>>& bookings, int n) {
    vector<int> diff(n + 2, 0);          // 注意是 n + 2
    for (int i = 0; i < (int)bookings.size(); i++) {
        int l = bookings[i][0];
        int r = bookings[i][1];
        int seats = bookings[i][2];
        diff[l] += seats;
        diff[r + 1] -= seats;
    }
    vector<int> ans(n);
    int preSum = 0;
    for (int i = 1; i <= n; i++) {
        preSum += diff[i];
        ans[i - 1] = preSum;
    }
    return ans;
}
```

## 复杂度

- 时间 $O(n + m)$：$m$ 次预订各 $O(1)$，再加一次 $O(n)$ 前缀和
- 空间 $O(n)$

对比暴力：每次预订都要改 $O(r-l+1)$ 个位置，最坏 $O(nm)$。

## 要点

### 1. 为什么数组要开 `n + 2`

航班编号是 `1..n`，**当 `r == n` 时，`r + 1 == n + 1`**。

- 开 `n + 1`（下标 `0..n`）→ **`diff[n+1]` 越界**
- 开 `n + 2`（下标 `0..n+1`）→ 刚好够 ✅

> **这是差分题唯一的坑：`r + 1` 一定会越界一位。**
> 你直接开了 `n + 2`，说明你想到了。

### 2. 差分为什么能"撤销"

`d[r+1] -= v` 的作用是让**从 `r+1` 开始的前缀和回到原来的水平**。

```
真实需求:  [0, 0, v, v, v, v, 0, 0]   (l=3, r=5)
差分数组:  [0, 0, v, 0, 0, 0, -v, 0]
前缀和:    [0, 0, v, v, v, v,  0, 0]   ← 还原成功
```

**每个"边界"都是一次开关：进区间开，出区间关。**

### 3. 下标的两种体系

本题航班是 **1-based**（`1..n`），返回数组是 **0-based**（`ans[0..n-1]`）。

```cpp
ans[i - 1] = preSum;   // 差分数组的 i → 答案数组的 i-1
```

**写差分时先想清楚"差分数组用哪套下标"，再统一全题。**

### 4. 差分能解决的三类问题

| 问题 | 做法 |
|---|---|
| 多次区间加，最后统一输出 | **本题** |
| 区间加 + 中途查询 | 差分不够 → 树状数组 |
| 二维区间加 | 二维差分（容斥） |
