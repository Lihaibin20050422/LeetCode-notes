# 88.merge(合并两个有序数组)

## 题目
给你两个按非递减顺序排列的整数数组 nums1 和 nums2，另有两个整数 m 和 n，分别表示 nums1 和 nums2 中的元素数目。
请你合并 nums2 到 nums1 中，使合并后的数组同样按非递减顺序排列。
注意：最终，合并后数组不应由函数返回，而是存储在数组 nums1 中。为了应对这种情况，nums1 的初始长度为 m + n，其中前 m 个元素表示应合并的元素，后 n 个元素为 0，应忽略。nums2 的长度为 n。
示例 1：
输入：nums1 = [1,2,3,0,0,0], m = 3, nums2 = [2,5,6], n = 3
输出：[1,2,2,3,5,6]

## 思路

**三指针 + 从后往前填**：在两个数组中分别设置指针 i 与 j，指向两个数组的最后一个元素，再设置一个指针 k，指向 nums1 的最后一个位置（下标 m+n-1）。

1. 比较 nums1[i] 与 nums2[j]，谁大就把谁放到 nums1[k]，然后对应指针前移，k 前移
2. 该操作一直持续到其中一个数组遍历完
3. 如果遍历完的是 j（j<0），说明 nums2 的元素已经全部放完，而 nums1 剩余的元素本身就在前面且有序，**不用处理**
4. 如果遍历完的是 i（i<0），说明 nums2 还有剩余元素，需要把它们依次搬到 nums1 的前面

用一个例子理解：`nums1 = [1,2,3,0,0,0], m = 3, nums2 = [2,5,6], n = 3`

```
i=2,j=2,k=5: 3 vs 6 → 放6 → [.,.,.,.,.,6]  j=1,k=4
i=2,j=1,k=4: 3 vs 5 → 放5 → [.,.,.,.,5,6]  j=0,k=3
i=2,j=0,k=3: 3 vs 2 → 放3 → [.,.,.,3,5,6]  i=1,k=2
i=1,j=0,k=2: 2 vs 2 → 放2 → [.,.,2,3,5,6]  j=-1,k=1
j<0 退出，剩余 while(j>=0) 跳过
结果：[1,2,2,3,5,6]
```

**为什么必须从后往前填？** 因为从前往后会覆盖 nums1 中还没比较的元素；从后往前时，`k` 指向的位置要么是 0 占位符、要么是已经被搬走的元素，永远是安全的。

## 代码
```cpp
class Solution {
public:
    void merge(vector<int>& nums1, int m, vector<int>& nums2, int n) {
        int i = m-1;
        int j = n-1;
        int k = m+n-1;
        while(i>=0&&j>=0){
            if(nums1[i]>nums2[j]){
                nums1[k] = nums1[i];
                i--;
            }else{
                nums1[k] = nums2[j];
                j--;
            }
            k--;
        }
        while (j >= 0) {
            nums1[k] = nums2[j];
            j--;
            k--;
        }
    }
};
```

## 复杂度

- 时间：$O(m+n)$，两个指针各自单向移动，总共不超过 m+n 次
- 空间：$O(1)$，原地合并，只用了三个指针变量

## 要点

- **注意处理可能剩余的 nums2 数组**：主循环退出后，只有 nums2 可能有剩余（nums1 剩余的本来就在正确位置）。这一步是本题最容易漏的地方，漏了就会丢掉 nums2 的前若干个较小元素。
- **从后往前是本题的关键**：正向合并需要额外 O(m) 空间来暂存 nums1，反向合并直接利用 nums1 尾部的空位，做到 O(1) 空间。
- **和"从前往后双指针"的区别**：这道题之所以反向，是因为"目标位置是空的"——利用这个性质才能原地合并。
- **`else` 分支处理相等的情况**：`nums1[i] == nums2[j]` 时取 nums2 的元素（本题不要求稳定性，取谁都行）。
