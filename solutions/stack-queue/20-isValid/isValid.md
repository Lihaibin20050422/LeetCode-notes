# 20.isValid(有效的括号)

## 题目
给定一个只包括 `'('`、`')'`、`'{'`、`'}'`、`'['`、`']'` 的字符串 s，判断字符串是否有效。
有效字符串需满足：左括号必须用**相同类型**的右括号闭合，且必须以**正确的顺序**闭合。

示例:
输入: s = "()"       → true
输入: s = "()[]{}"   → true
输入: s = "(]"       → false
输入: s = "([)]"     → false
输入: s = "{[]}"     → true

## 思路

**栈**。

扫描字符串：
- 遇到**左括号** → 入栈（先记账）
- 遇到**右括号** → 和栈顶的左括号配对：
  - 栈为空 → 说明右边多了，返回 `false`
  - 弹出栈顶，若和当前右括号**不匹配** → 返回 `false`
- 扫完整个串后，**栈必须为空**（否则左边多了）

## 代码
```cpp
class Solution {
public:
    bool isValid(string s) {
        stack<char> S;
        for(char c : s){
            if(c == '(' || c == '[' || c == '{'){
                S.push(c);
            }else{
                if(S.empty()) return false;      // 右括号多余
                char top = S.top(); S.pop();
                if((c == ')' && top != '(') ||
                   (c == ']' && top != '[') ||
                   (c == '}' && top != '{')) return false;   // 类型不匹配
            }
        }
        return S.empty();                        // 左括号是否全部闭合
    }
};
```

## 复杂度

- 时间：$O(n)$，每个字符进出栈各一次
- 空间：$O(n)$，栈最坏存下全部左括号

## 要点

### 1. 为什么是"栈"

括号匹配的本质是**嵌套**——**最近一个没配对的左括号，最先被配对**。这正是**后进先出（LIFO）**，也就是栈唯一的规则。

> 一句话：**看到"嵌套 / 最近优先 / 回退"，就用栈。**

### 2. 三种失败情况，一个都不能漏

| 情况 | 例子 | 在哪里被抓住 |
|---|---|---|
| 右括号多余 | `")"` | 弹栈时 `S.empty()` |
| 左右类型不匹配 | `"(]"` | 弹出后比较类型 |
| 左括号多余 | `"("` | 循环结束后 `S.empty()` 为 false |

### 3. 这就是你 DS 里写的"括号匹配"

408 栈的应用里那个经典例子（"检验括号是否匹配"），**和这道题是同一个算法**。
区别只是 408 用 C 手写栈、这里用 STL 的 `stack`。
