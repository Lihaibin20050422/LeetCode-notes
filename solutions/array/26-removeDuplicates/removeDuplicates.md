# 26.removeDuplicates( 删除有序数组中的重复项)

## 题目
给你一个非严格递增排列的数组 nums，请你使用原地算法删除重复出现的元素，使每个元素只出现一次，返回删除后数组的新长度。元素的相对顺序应该保持一致。然后返回 nums 中唯一元素的个数。  
考虑 nums 的唯一元素的数量为 k。去重后，返回唯一元素的数量 k。  
nums 的前 k 个元素应包含排序后的唯一数字。下标 k‑1 之后的剩余元素可以忽略。  

## 思路

**双指针（快慢指针）**：快指针 `i` 遍历数组，慢指针 `k` 记录"去重后该放的位置"。

1. 慢指针 `k` 从 1 开始——因为 `nums[0]` 一定保留（第一个元素不可能重复）
2. 快指针 `i` 也从 1 开始遍历整个数组
3. 数组是有序的，所以相邻元素相等就是重复——判断 `nums[i] != nums[i-1]`
4. 遇到不重复的元素，就把它搬到 `k` 的位置，然后 `k` 前移一步：`nums[k++] = nums[i]`
5. 遍历结束，`k` 就是去重后数组的长度

用一个例子理解：`nums = [0, 0, 1, 1, 1, 2]`

```
k=1
i=1: nums[1]==nums[0]（0==0）→ 跳过
i=2: nums[2]!=nums[1]（1!=0）→ nums[1]=1, k=2
i=3: nums[3]==nums[2]（1==1）→ 跳过
i=4: nums[4]==nums[3]（1==1）→ 跳过
i=5: nums[5]!=nums[4]（2!=1）→ nums[2]=2, k=3
返回 k=3，前三个元素是 [0,1,2]
```

## 代码
```cpp
class Solution {
public:
    int removeDuplicates(vector<int>& nums) {
        if(nums.empty()){
            return 0;
        }
        int k = 1;
        for(int i=1;i<nums.size();i++){
            if(nums[i]!=nums[i-1]){
                nums[k++] = nums[i];
            }
        }
        return k;
    }
};
```

## 复杂度

- 时间：$O(n)$，快指针 `i` 遍历一次数组
- 空间：$O(1)$，原地算法，只用了两个变量 `i` 和 `k`

## 要点

- **`k` 为什么从 1 开始**：`nums[0]` 是第一个元素，不可能和"前面的"重复，一定保留，所以从下标 1 开始装不重复的元素。
- **为什么用相邻比较**（`nums[i] != nums[i-1]`）：因为数组是**有序**的，所有相同的元素一定挨在一起，相邻比较就够了，不需要哈希表或嵌套循环。
- **`nums[k++] = nums[i]` 一句话干两件事**：先把 `nums[i]` 复制到 `k` 位置，再把 `k` 加 1。这是快慢指针的经典写法。
- **这是最优解**：`O(n)` 时间 + `O(1)` 空间，比"用哈希表去重再拷回"（额外 O(n) 空间）和"发现重复就 erase"（erase 是 O(n)，总复杂度 O(n²)）都更好。
