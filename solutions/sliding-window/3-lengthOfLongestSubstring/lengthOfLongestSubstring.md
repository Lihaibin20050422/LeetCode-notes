# 3. 无重复字符的最长子串

## 题目

给定一个字符串 `s`，找出其中**不含重复字符**的**最长子串**的长度。

示例：`s = "abcabcbb"` → `3`（`"abc"`）；`s = "pwwkew"` → `3`（`"wke"`）

## 思路：窗口里"没有重复"，冲突就跳

维护一个窗口 `[left, right]`，保证窗口内字符互不相同：

- 右指针每次吞进一个字符 `c`；
- 哈希表记 `c` **最近一次出现的下标**；
- 如果 `c` 上次出现的位置**还在窗口里**，说明重复了 → 把 `left` **直接跳到那个位置的下一位**；
- 每轮更新 `maxLen = right - left + 1`。

### 关键：不是"缩一格"，是"跳"

遇到重复时，`left` 不必一格一格往右挪——可以直接跳到 `idx[c] + 1`。
因为 `idx[c]` 及其左边都已经被证明不可能更长了（窗口里已经有重复）。

### 更关键：必须判断 `idx[c] >= left`

```cpp
if (idx.find(c) != idx.end() && idx[c] >= left)
```

**少了 `idx[c] >= left` 就会错**——哈希表记的是"历史上"的位置，但那个位置可能**早就滑出窗口了**，此时 `left` 不能往回跳。

两个反例：

| 输入 | 正确 | 少了判断会得到 |
|---|---|---|
| `"abba"` | 2 | 3（处理最后的 `a` 时，把 left 拉回到 1） |
| `"tmmzuxt"` | 5 | 4（处理最后的 `t` 时，left 被拉回到 1） |

> **一句话：哈希表记得太全，反而要自己筛一遍“这个位置还在不在窗口里”。**

## 代码

```cpp
int lengthOfLongestSubstring(string s) {
    unordered_map<char, int> idx;      // 字符 -> 最近一次出现的下标
    int maxLen = 0, left = 0;
    for (int right = 0; right < (int)s.size(); right++) {
        char c = s[right];
        if (idx.find(c) != idx.end() && idx[c] >= left) {
            left = idx[c] + 1;         // 跳到重复字符的下一位
        }
        idx[c] = right;
        maxLen = max(maxLen, right - left + 1);
    }
    return maxLen;
}
```

## 复杂度

- 时间 $O(n)$：`right` 走 $n$ 步，`left` 只增不减（均摊 $O(n)$）；哈希均摊 $O(1)$
- 空间 $O(\min(n, |\Sigma|))$，字符集有限时是常数

## 要点

### 1. 和 209 是"同一副骨架，两种触发条件"

| | 209（和 ≥ target） | **3（窗口内无重复）** |
|---|---|---|
| 何时缩 | `sum >= target` | 新字符与窗口内字符重复 |
| 缩多少 | 一格一格缩（`while`） | **直接跳到 `idx[c] + 1`** |
| 为什么能跳 | 收敛条件要一格一格试 | 左边界有确定的"唯一下界" |

**共同点：两个指针都不回头，总操作 $O(n)$。**

### 2. 为什么哈希存下标，而不是存"出现过没有"

存 `bool` 只能告诉你"重复了"，但你还需要知道**跳到哪里**。
存**最近一次出现的下标**，才能一次跳到位。

### 3. 字符集小时，用数组代替 `unordered_map`

ASCII 只有 128 个字符，`unordered_map` 的哈希开销完全可以省掉：

```cpp
int pos[128];
fill(pos, pos + 128, -1);      // -1 表示没出现过
// ...
if (pos[c] >= left) left = pos[c] + 1;
pos[c] = right;
```

更快、更省，笔试和面试都更讨喜。

### 4. 边界

| 输入 | 输出 |
|---|---|
| `""` | `0` |
| `"a"` | `1` |
| `"abba"` | `2` |
