# 1. Two Sum（两数之和）

**难度**：Easy
**标签**：数组、哈希表
**日期**：2026-08-06

## 题目

给定一个整数数组 `nums` 和一个目标值 `target`，找出数组中和为 `target` 的两个数的下标。假设每种输入只有一个答案，同一个元素不能使用两次。

## 思路

**暴力法**：用两层循环遍历每一对元素 `(i, j)`，检查 `nums[i] + nums[j]` 是否等于 `target`。等于则直接返回 `{i, j}`。

外层循环 `i` 从 `0` 到 `n-2`，内层循环 `j` 从 `i+1` 到 `n-1`。这样每一对元素只检查一次，不会重复。

## 代码

```cpp
class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        int n = nums.size();
        for (int i = 0; i < n - 1; i++) {
            for (int j = i + 1; j < n; j++) {
                if (nums[i] + nums[j] == target) {
                    return {i, j};
                }
            }
        }
        return {};  // 题目保证有解，不会走到这里
    }
};
```

## 复杂度

- 时间：$O(n^2)$ —— 两层循环，最坏情况检查 `n(n-1)/2` 对
- 空间：$O(1)$ —— 只用了两个循环变量

## 优化方向

暴力法在数据量大时会超时。可以用**哈希表**把时间复杂度降到 $O(n)$：遍历时检查 `target - nums[i]` 是否已在哈希表中，在的话直接返回，不在的话把当前元素存进去。等你学完哈希表专题再回来用那种写法重做这道题。
